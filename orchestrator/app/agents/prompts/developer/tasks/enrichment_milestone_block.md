## Milestone enrichment — primary expansion for this pass
This is the **one big idea** for this enrichment iteration. Implement a substantial new capability or major feature expansion — not polish.

- Deliver a complete, user-visible feature area: new flows, screens, data models, and API surface.
- Think product expansion: new functionality that makes the app significantly more useful, not incremental tweaks.
- Touch backend and frontend together — wire full journeys with persistence, validation, and tests.
- Include pytest coverage for new API behavior and verify the feature works through the live preview.
- Do **not** stop at scaffolding or a thin slice — ship something a user could actually use end-to-end.
