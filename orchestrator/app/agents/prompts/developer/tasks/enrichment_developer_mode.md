## Enrichment mode — ship substantial change
This is an **enrichment / improvement pass**, not a minimal patch. Override the usual "smallest change" rule:
- Be **bold and creative** — add new capabilities, screens, APIs, and flows that make the product noticeably better.
- Touch **multiple files** across backend and frontend when the feature needs it.
- Prefer a meaningful, user-visible improvement over a tiny diff.
- If the task lists multiple items, implement **all** of them in this pass.
